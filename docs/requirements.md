# Learning OS Requirements

## Problem

I want to study consistently without needing to spend a lot of
mental energy deciding what to do.

## What I want

I want a tool that makes it easier to organize my ideas, goals,
learning paths and projects.

The system should give me a structured but flexible way of learning.

I want the system to:

- Help me organize learning goals.
- Break large goals into smaller achievable tasks.
- Tell me what I should focus on today.
- Make progress visible.
- Give me a rewarding feeling when I complete something.
- Allow me to work on multiple learning areas.
- Adapt to my available time and energy.
- Connect learning with practical projects.

## What I don't want

I don't want Learning OS to make people feel stressed.

It should feel like a tool that helps rather than another productivity
system demanding things from me.

It should:

- Avoid excessive notifications.
- Avoid punishing missed days.
- Avoid making users feel like they are failing.
- Avoid unnecessary complexity.
- Make starting a learning session easy.

## My ideal daily experience

I open the application and immediately see what I should do today.

The application should give me a small, realistic set of tasks that
moves me towards my goals.

For example:

1. Start a 20-minute technical learning session.
2. Complete a small practical exercise.
3. Do a short Luxembourgish session.

If I skip a day, the system should not punish me.

Instead, it should reassess my plan and adjust future sessions.

The goal is consistency, not perfection.

## First version

The first version should be simple.

It should allow me to:

- Create learning goals.
- Define smaller tasks related to those goals.
- See what I should do today.
- Mark tasks as completed.
- Track progress.
- Adjust the plan when tasks are skipped.
