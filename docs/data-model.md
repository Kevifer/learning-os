# Learning OS Data Model

## What does Learning OS need to remember?

### 1. Goals

The things the person wants to learn or achieve.

Examples:
- Kubernetes certification
- Learn Ansible
- Learn Luxembourgish

### 2. Tasks

The smaller pieces of work needed to reach a goal.

### 3. Achievements / Progress

What the person has already learned or completed.

### 4. Learning Sessions

When the person actually studied and for how long.

### 5. Preferences

How the person prefers to learn.

Examples:
- Preferred learning time
- Available time
- Preferred session length
- Different preferences for different learning areas

### 6. Projects

Practical projects where the person can apply what they learn.

### 7. Achievements

Things the person has learned or accomplished.

An achievement represents a meaningful outcome rather than simply
completing a task.

Examples:
- Learned Kubernetes Pods
- Completed CKAD certification
- Built first FastAPI application

Achievements can be associated with a Goal and record when they
were achieved.
