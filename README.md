# Learning OS

A personal learning management platform designed to make continuous learning
simple, sustainable and personalized.

## Why?

Learning is easier to sustain when the system adapts to the person rather
than forcing the person to adapt to the system.

Learning OS is an experiment to build a learning system around the way I
actually learn.

## Initial Goals

- Track learning goals
- Organize skills and certifications
- Plan small daily learning sessions
- Track progress
- Connect learning with practical projects

## Current Focus

- Python
- FastAPI
- PostgreSQL
- Docker
- DevOps / Platform Engineering
